## 🎯 What Is This?

A **Python-based brute Force** that demonstrates how dictionary attacks work in a controlled, mock environment.

Perfect for:
- 🎓 Students learning cybersecurity concepts
- 🔬 Researchers studying attack patterns
- 🧪 Penetration testers practicing in safe labs

---

## ✨ Features

<div align="center">

| Feature | Description |
|:-------:|:------------|
| ⚡ **Multi-Threading** | Tests multiple passwords simultaneously |
| 📊 **Live Progress Bar** | Real-time feedback with `tqdm` |
| 📝 **Hit Logging** | Saves successful matches to `hits.txt` |
| 🔧 **Custom Wordlist** | Bring your own password list |
| 🎨 **Colorful Output** | Clean terminal UI with `colorama` |
